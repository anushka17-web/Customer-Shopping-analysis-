# Customer Shopping Behavior Analysis

## Overview

Customer Shopping Behavior Analysis is an end-to-end data analytics project that explores customer purchasing patterns, spending behavior, product preferences, and shopping trends.

The project uses Python, Pandas, MySQL, and Power BI to transform raw customer shopping data into meaningful business insights. The workflow includes exploratory data analysis (EDA), data cleaning, feature engineering, SQL-based business analysis, and interactive dashboard development.

**Objective:** Analyze customer shopping behavior and identify insights that support data-driven business decisions.

## Dataset

The project uses the `customer_shopping_behavior.csv` dataset.

- **Total records:** 3,900
- **Original columns:** 18
- **Data type:** Customer shopping and transaction-related data

### Key Attributes

- Customer ID, age, and gender
- Purchased items and product categories
- Purchase amount and review ratings
- Customer location, size, color, and season
- Subscription status and shipping type
- Discount usage and previous purchases
- Payment method and purchase frequency

## Project Workflow

### 1. Data Loading

- Imported the CSV dataset into Python using Pandas.
- Inspected the dataset using `head()`, `info()`, and `describe()`.
- Examined the dataset structure, data types, and statistical summaries.

### 2. Exploratory Data Analysis (EDA)

- Analyzed numerical and categorical columns.
- Identified missing values and examined numerical distributions.
- Checked skewness in numerical features.
- Explored customer demographics and purchasing attributes.

### 3. Data Cleaning and Feature Engineering

- Handled missing review ratings using category-wise median imputation.
- Standardized column names into lowercase and snake_case format.
- Renamed the purchase amount column for easier analysis.
- Created age groups using quantile-based binning.
- Converted purchase frequency categories into approximate day values.
- Removed the redundant `promo_code_used` column after checking its consistency with `discount_applied`.

### 4. SQL Analysis Using MySQL

Loaded the processed DataFrame into the `customer` table in the `customer_shopping_behavior` database using SQLAlchemy and PyMySQL.

The SQL script addresses the following business questions:

1. What is the total revenue generated by male and female customers?
2. Which customers used discounts but spent at least the average purchase amount?
3. Which five products have the highest average review ratings?
4. How do average purchase amounts compare between Standard and Express shipping?
5. How do subscriber and non-subscriber spending patterns compare?
6. Which five products have the highest percentage of discounted purchases?
7. How can customers be segmented into New, Returning, and Loyal groups?
8. What are the three most purchased products within each category?
9. How many repeat buyers belong to each subscription group?
10. How is revenue distributed across age groups?

SQL concepts used include:

- `SELECT`, `WHERE`, `GROUP BY`, and `ORDER BY`
- Aggregate functions such as `SUM()`, `AVG()`, and `COUNT()`
- Subqueries and conditional aggregation
- `CASE` statements and Common Table Expressions (CTEs)
- Window functions such as `ROW_NUMBER()`

### 5. Power BI Dashboard

Developed an interactive Power BI dashboard to summarize customer shopping metrics and explore patterns across customer segments.

**Key Performance Indicators:**

- Average Review Rating
- Average Purchase Amount
- Number of Customers

**Dashboard analysis includes:**

- Subscription status analysis
- Purchase amount and customer count by category
- Age-group comparisons
- Interactive filters for gender, category, shipping type, and subscription status

### 6. Reporting and Presentation

- Summarize the methodology and findings in a project report.
- Prepare a presentation using Gamma to communicate the business questions, analysis, findings, and recommendations.

## How to Run the Project

### Prerequisites

- Python 3.x
- VS Code with Python and Jupyter extensions
- MySQL Server and MySQL Workbench
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
cd Customer-Shopping-Behavior-Analysis
```

### Step 2: Install Python Dependencies

Run the following command in the VS Code terminal:

```bash
python -m pip install pandas sqlalchemy pymysql
```

### Step 3: Load and Analyze the Dataset

Open `Customer_Shopping_Behavior.ipynb` in VS Code.

Run the notebook cells in sequence to load the CSV, explore the data, handle missing values, and create additional analytical features.

The `main.py` file also contains the basic CSV-loading step.

### Step 4: Configure MySQL

1. Start MySQL Server and open MySQL Workbench.
2. Create the project database:

```sql
CREATE DATABASE customer_shopping_behavior;
USE customer_shopping_behavior;
```

3. Configure your MySQL connection in the notebook.
4. Execute the notebook cell that loads the processed DataFrame into the `customer` table.

**Security note:** Never publish your database password in a notebook or GitHub repository. Use environment variables or another secure configuration method.

### Step 5: Run SQL Queries

Open `customer_shopping_behavior.sql` in MySQL Workbench.

Ensure the `customer` table exists, then execute the queries to perform the business analysis.

### Step 6: Open the Power BI Dashboard

Open `customer_shopping_behavior.pbix` in Power BI Desktop.

Configure the data source if prompted, refresh the data if necessary, and explore the dashboard using its KPI cards, charts, and filters.
